## Brand & Style

This design system establishes a high-tier, enterprise-grade aesthetic for high-throughput AI platforms and cloud hosting infrastructure. The visual direction merges strict enterprise precision with an atmospheric, bioluminescent dark forest aesthetic. It avoids generic gray/slate dark modes in favor of deep obsidian-pine depths, tempered glassmorphism, and surgical mint accents.

The emotional profile conveys:
- **Sovereign Security:** Immovable, dense infrastructure built on deep obsidian-green rock foundations.
- **Cognitive Clarity:** Sharp, high-contrast, laser-focused data rendering designed for mission-critical monitoring, LLM model orchestration, and telemetry.
- **Refined Luminescence:** Restrained mint light sources that emulate fiber optics, laser emitters, and liquid-cooled core processors without introducing visual fatigue or neon gimmicks.

The design movement balances **Glassmorphism** and **Technical Minimalism**. Translucent frosted overlays, subtle emerald-tinted specular borders, and high-legibility typographic hierarchies provide immediate signal amidst heavy data density.

## Colors

The palette relies on stacked layers of deep forest minerals, dense obsidian blacks, and high-frequency emerald-to-mint spectrums. Every surface is tuned with subtle green undertones to ensure visual continuity.

### Surface Architecture
- **Base Canvas (`#040a07`):** The deepest void tone. Absorbs low-frequency distractions, anchoring full-page canvases and foundational viewports.
- **Surface Level 1 (`#07130e`):** Standard container background for persistent navigation, rail drawers, and underlying modular trays.
- **Surface Level 2 (`#0c1c15`):** Elevated cards, interactive dashboard nodes, table rows, and dialogue surfaces.
- **Surface Level 3 / Active Glass (`#13281f` at 60-80% opacity):** Modal overlays, dropdown menus, floating action docks, and flyovers.

### Brand & Interactive Tiers
- **Primary Emerald (`#059669` / `#047857` hover):** Anchors confident calls-to-action, active status anchors, and primary brand markers.
- **Luminous Mint Secondary (`#34d399`):** Accent indicators, active micro-metrics, dynamic line charts, and selected states.
- **Radiant Sage Tertiary (`#6ee7b7`):** Monospaced code highlights, low-intensity data badges, and specular highlights.

### Functional & Neutral Signals
- **Text Primary (`#f2fbf6`):** Pure crystalline sage-white for headlines and high-priority data points. Minimum 12:1 contrast against `#040a07`.
- **Text Secondary (`#94a89d`):** Cool eucalyptus gray for secondary descriptions, table headers, and metadata.
- **Text Muted (`#4b6356`):** Deep pine-slate for inactive icons, disabled states, and placeholder texts.
- **Borders & Dividers:** Glass borders use `#1b3a2c` at 60% opacity with a top-lit gradient edge hitting `#34d399` at 20% opacity.
- **Alert States:** Success uses `#10b981`, Warning uses `#f59e0b`, and Critical Error uses `#ef4444` balanced against the dark emerald environment.

## Typography

The typographic hierarchy balances structural precision with developer utility:

1. **Headlines (`Space Grotesk`):** Delivers a deliberate, tech-forward character with crisp geometric apexes and tight tracking. Used for major dashboards, system KPIs, and promotional architecture headers.
2. **Body (`Geist`):** Implements a high-density, neutral workhorse optimized for readability across log streams, configuration panels, deep data trees, and long-form technical documentation.
3. **Labels & Metadata (`JetBrains Mono`):** Dedicated to technical readouts, GPU/CPU telemetry, memory address allocations, API endpoints, tokens, and micro-tags.

All monospaced labels must be rendered in uppercase when applied to system indicators or status tags to create structural contrast against regular copy.

## Layout & Spacing

This design system uses an enterprise fluid 12-column grid on desktop and scales down dynamically to maintain data density:

- **Desktop (1440px and wider):** 12 columns, 24px (`gutter`) gutters, 40px (`margin`) outer margins. Data-intensive analytical consoles can opt into a full-bleed viewport utilizing `margin-sm` (16px) with fixed-width persistent rails.
- **Tablet (768px – 1439px):** 8 columns, 16px (`gutter-sm`) gutters, 24px outer margins. Secondary sidebar panels collapse into flyout glass draw panels.
- **Mobile (below 768px):** 4 columns, 16px gutters, 16px (`margin-sm`) margins. Data cards break down into stacked single-column streams.

### Spacing Rhythm
Built upon a strict 4px base unit. Internal component padding follows compact boundaries:
- Micro-elements (tags, chips, input heights): `space-xs` (4px) and `space-sm` (8px).
- Containers, card bodies, and toolbars: `space-md` (16px) and `space-lg` (24px).
- Structural section gaps: `space-xl` (40px).

## Elevation & Depth

Visual hierarchy is maintained via stacked tonal glass tiers paired with internal specular highlights and faint emerald ambient halos. Real-world physical cast shadows are replaced with optical luminosity that interacts with deep forest obsidian surfaces.

### Depth Tiers
1. **Level 0 (Canvas Base):** Surface `#040a07`. Completely flat, non-reflective.
2. **Level 1 (Sub-Panels & Structural Grids):** Surface `#07130e` with a 1px solid perimeter border (`#13281f`). Zero shadow.
3. **Level 2 (Interactive Modules & Cards):** Surface `#0c1c15` with a subtle linear gradient fill (180deg: `rgba(16, 185, 129, 0.04)` to `rgba(4, 10, 7, 0)`). 
   - Border: 1px `rgba(52, 211, 153, 0.12)`.
   - Shadow: `0 4px 20px -2px rgba(0, 0, 0, 0.7)`.
4. **Level 3 (Modals, Popovers, Active Drawers):** Liquid Glass effect.
   - Background: `rgba(12, 28, 21, 0.72)`.
   - Backdrop Filter: `blur(16px) saturate(140%)`.
   - Border: 1px top-lit specular gradient border (top: `rgba(110, 231, 183, 0.3)`, bottom: `rgba(19, 40, 31, 0.4)`).
   - Shadow: `0 12px 32px -4px rgba(0, 0, 0, 0.85), 0 0 24px 0 rgba(5, 150, 105, 0.08)`.
5. **Level 4 (Active State Glow):** Triggered on focused controls, running workloads, and hovered primary assets.
   - Outer glow: `0 0 16px -2px rgba(16, 185, 129, 0.35)`.

## Shapes

The design uses a soft architectural corner language (`roundedness: 1`). Enterprise tools require maximum spatial efficiency: soft, measured corners (4px base) maximize grid density and preserve clean horizontal/vertical data scanlines without the brutalist harshness of sharp 90-degree corners.

- **Micro Controls (Badges, Chips, Inputs, Buttons):** `0.25rem` (4px).
- **Cards, System Tiles, & Modules (`rounded-lg`):** `0.5rem` (8px).
- **Modals, Floating Panels, & Trays (`rounded-xl`):** `0.75rem` (12px).
- **Nodes, Terminal Logs, and Code Inlines:** `0.25rem` (4px).
- **Circular Indicators (Avatars, Ping status lights):** Fully rounded `9999px`.

## Components

### Buttons
- **Primary:** Background `#059669`, transition to `#047857` on hover. Text `#ffffff` font `Geist` 13px weight 500. Subtle top inner highlight (`inset 0 1px 0 rgba(255, 255, 255, 0.2)`). Focused state triggers Level 4 emerald glow.
- **Secondary / Glass:** Background `rgba(12, 28, 21, 0.65)` with 1px border `rgba(52, 211, 153, 0.2)`. Text `#f2fbf6`. Hover shifts background to `rgba(19, 40, 31, 0.85)` with border color shifting to `#34d399`.
- **Ghost:** Transparent background, text `#94a89d`. On hover, text shifts to `#6ee7b7` with background tint `rgba(5, 150, 105, 0.08)`.

### Input Fields & Controls
- **Text Inputs & Selects:** Height 36px (dense enterprise standard). Background `#07130e` with a 1px border `#1b3a2c`. Active text `#f2fbf6`, placeholder text `#4b6356`. On focus: border shifts to `#10b981`, and a 2px diffuse emerald glow ring (`rgba(16, 185, 129, 0.2)`) illuminates the container perimeter.
- **Checkboxes & Radios:** 16px square/circle. Unchecked: 1px border `#244b39` on `#07130e`. Checked: solid `#059669` fill with crisp `#040a07` vector check/pip.

### Status Chips & Badges
- Constructed with `JetBrains Mono` 11px uppercase.
- **Online / Running:** Background `rgba(16, 185, 129, 0.12)`, border 1px `rgba(52, 211, 153, 0.25)`, text `#34d399`. Accompanied by a 6px breathing emerald radial pulse indicator.
- **Warning / Degraded:** Background `rgba(245, 158, 11, 0.12)`, border 1px `rgba(245, 158, 11, 0.3)`, text `#fbbf24`.
- **Idle / Neutral:** Background `rgba(19, 40, 31, 0.6)`, border 1px `#1b3a2c`, text `#94a89d`.

### Cards & Module Containers
- Constructed on Surface Level 2 (`#0c1c15`).
- Header bands incorporate subtle 1px bottom divider `#13281f`.
- Card titles utilize `title-sm` (`Geist` 16px semi-bold) in `#f2fbf6` with optional trailing monospaced health/version metrics in `#6ee7b7`.

### Data Tables & Log Streamers
- Tables use zebra-alternate lines via `transparent` and `rgba(7, 19, 14, 0.4)`. Row hover illuminates row line to `rgba(16, 185, 129, 0.04)` with a left 2px `#10b981` border indicator.
- Log streamers: Raw canvas `#040a07` embedded sub-window with a 1px border `#13281f`. Body text rendered in `JetBrains Mono` 12px using `#94a89d`, highlighting timestamp tokens in `#4b6356` and JSON keys in `#34d399`.
